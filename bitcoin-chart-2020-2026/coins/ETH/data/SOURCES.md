# Ethereum film sources

Prepared 2026-10-27. Prices and price milestones come only from the saved TradingView daily candles.

## Prices

Compared `INDEX:ETHUSD`, `CRYPTO:ETHUSD` and `KRAKEN:ETHUSD` with `fetch-tradingview.js --print`.
The first two returned 4,095 candles beginning 2015-08-07; Kraken returned 4,094 with the same first date.
Selected `INDEX:ETHUSD`. Exclude the current UTC day's unfinished candle from the saved film input.
No synthetic price anchors are supplied. Any filled gaps are explicitly marked estimated in generated daily data.
The saved file contains 4,094 actual candles through 2026-10-26. Missing dates are 2015-08-09, 2015-08-10,
2015-09-04, 2015-09-21 and 2015-10-10; `make-data.js` fills them with flat interpolated candles, as for Bitcoin.

## Events

The requested 99Bitcoins Ethereum historical-price URL redirected to its Bitcoin page when checked in a browser.
Use the following primary sources for Ethereum-specific events; do not imply 99Bitcoins supplied an ETH timeline.
Labels identify events, without asserting that an event caused a particular price movement.

- Protocol upgrade dates, from Homestead through Fusaka: https://ethereum.org/ethereum-forks
- DAO exploit (2016-06-17): https://blog.ethereum.org/2016/06/17/critical-update-re-dao-vulnerability
- Uniswap launch (2018-11-02): https://blog.uniswap.org/uniswap-history
- SEC approval of Ether ETP listing rule changes (2024-05-23): https://www.sec.gov/rule-release/34-100224
- Ether ETP trading launch (2024-07-23): https://www.sec.gov/Archives/edgar/data/1725210/000095017024085501/etheeth_press_release_7.htm
- Shared market events (COVID crash, China crypto ban, LUNA collapse, FTX bankruptcy): dates and labels already verified
  in the Bitcoin project's `data/events.csv`, sourced from https://99bitcoins.com/cryptocurrency/bitcoin/historical-price/.
- ATH/ATL dates and amounts: generated by `detect-phases.js` and `score.js` from this coin's TradingView data.
